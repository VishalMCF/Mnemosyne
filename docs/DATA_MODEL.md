# Data model

The schema is defined in `packages/database/src/schema.ts` and migrations are generated into `packages/database/migrations/` with Drizzle Kit.

| Entity | Responsibility | Key constraints |
| --- | --- | --- |
| `sources` | Imported collections | Local origin and lifecycle state |
| `documents` | Original Markdown files | SHA-256 fingerprint; source ownership |
| `sections` | Parsed document hierarchy | Stable document location and parent hierarchy |
| `chunks` | AI processing units | References a document/section and deterministic order |
| `diagrams` | Mermaid source and extracted metadata | Preserve original text, location, type, and extraction confidence |
| `concepts` | Extracted knowledge | Must have source provenance |
| `relationships` | Knowledge graph edges | Provenance and relationship kind |
| `exercises` | Generated training material | References one or more source concepts; versioned generation |
| `sessions` | Learning sessions | Local timestamps and session state |
| `session_items` | Exercises assigned to a session | Session order and completion state |
| `responses` | Learner answers and evaluations | Immutable history tied to exercise version |
| `review_states` | Per-exercise scheduling | Independent exercise dimension and due date |
| `mastery_states` | Per-concept mastery | Separate mastery by capability/exercise type |

Deleting a source explicitly removes its dependent concepts, exercises, responses, review state, and now-empty sessions. Reprocessing replaces current extracted artifacts while preserving historical sessions, responses, and review history. AI-generated concepts, exercises, and evaluations carry model and prompt/schema version metadata.

## SQLite policy

The database lives under ignored `data/database/` by default. Enable foreign-key enforcement and use transactions for multi-record operations. Migrations are generated by Drizzle Kit and committed as source; database files are never committed.

Concept and exercise rows carry generation version, provider model, and prompt version. Re-extraction marks prior knowledge and exercises historical, then creates current rows while retaining old responses. Matching concept mastery is copied forward when concepts are re-extracted. Removing a source explicitly removes its concepts, exercises, responses, review state, and now-empty session rows.
